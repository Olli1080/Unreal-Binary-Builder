# 4.0.0 (Avalonia Cross-Platform Port)

**MAJOR ARCHITECTURAL UPDATE**
* **Cross-Platform**: Unreal Binary Builder has been fully rewritten in Avalonia UI (.NET 10.0), allowing it to run natively on Windows, Linux, and macOS.
* **Modern UI**: Replaced the legacy WPF interface with a modern, responsive Fluent UI (NavigationView, ContentDialogs, Theme switching).
* **Improved Performance**: Background build orchestration is now fully asynchronous, preventing UI freezes during massive engine compilations.
* **Code Editor**: Upgraded the integrated code editor using `AvaloniaEdit` with full cross-platform file saving support.
* **Updater Migration**: Replaced the separate `UnrealBinaryBuilderUpdater` app with a fully integrated `NetSparkle.Avalonia` cross-platform updater.
* **Analytics & Stability**: Sentry v5 integration and GameAnalytics have been fully ported and stabilized.
