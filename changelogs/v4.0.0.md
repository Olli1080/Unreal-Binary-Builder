# 4.0.0 (Avalonia Cross-Platform Port)

**MAJOR ARCHITECTURAL UPDATE**
* **Cross-Platform**: Unreal Binary Builder has been fully rewritten in Avalonia UI (.NET 10.0), allowing it to run natively on Windows, Linux, and macOS.
* **Service-Oriented Architecture**: Refactored the legacy "God ViewModel" into specialized, testable services (IEngineBuild, ISetup, IPluginBuild, IGit, ILogging).
* **Modern UI**: Replaced the legacy WPF interface with a modern, responsive Fluent UI (NavigationView, ContentDialogs, Theme switching).
* **Visual Build Stepper**: Real-time visual feedback of the current build stage (Setup -> Build -> Package).
* **Advanced Orchestration**: Implemented stateful build tracking with "Smart Resume" logic, allowing recovery from failed stages without restarting the entire process.
* **Build History & Persistence**: Full dashboard of past build attempts including status, durations, configurations, and archived log viewing.
* **Log Syntax Highlighting**: Custom Unreal Engine log highlighting for `AvaloniaEdit`, making errors and warnings instantly scanable.
* **Velopack Integration**: Migrated from legacy NetSparkle to Velopack for a modern, GitHub-native update experience and automated installers.
* **CI/CD Pipeline**: Integrated GitHub Actions for automated verification on Windows, Linux, and macOS with automated release generation.
* **Documentation Automation**: Built-in tool to automatically regenerate documentation screenshots to ensure they are always up-to-date.
* **Build Hygiene**: Resolved all compiler and SDK warnings for a 100% clean build.
* **Privacy & Identity**: Updated for the Olli1080 fork with legacy telemetry disabled and proper legal attribution.
